# Grand Life Adventures

A comprehensive GTA V mod that adds deep relationship mechanics, life choices, family systems, and visual enhancements to create a richer single-player experience.

## Features

### 🤝 Relationship System
- Choose and pursue romantic relationships with multiple characters
- Build relationship stats through activities and interactions
- Dating mechanics with location-based activities
- Breakup and reconciliation options

### 🌍 Life Choices & Career
- Multiple career paths with different income and prestige rewards
- Lifestyle choices that impact gameplay and story
- Education and skill development system
- Financial management and property ownership

### 👨‍👩‍👧‍👦 Family & Parenting
- Start a family with a romantic partner
- Parenting mechanics and child development
- Family activities and bonding
- Inheritance and family legacy system

### 🎨 Visual Enhancements
- Enhanced character customization options
- Improved UI/UX for relationship and life management
- Custom menu themes and overlays
- Visual indicators for relationship status and life choices

## Installation

1. Download the latest release
2. Extract to your GTA V installation directory
3. Run the provided batch script to auto-detect and install
4. Launch GTA V and enjoy!

## System Requirements

- GTA V (Steam, Epic Games, or Rockstar Games Launcher)
- ScriptHook V
- .NET Framework 4.7.2+
